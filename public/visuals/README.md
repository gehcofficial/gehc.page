# Static mirror — Website Visual [PUBLIK]

File di folder ini dilayani langsung dari CDN Vercel (cepat).

**Jangan edit manual di sini.** Sumber kebenaran tetap Google Drive.
Sinkronkan dengan:

```powershell
npm run drive:pull-visuals:staging   # atau :prod
git add public/visuals/
git commit -m "chore(visuals): sync from Drive"
git push
```

Manifest `manifest.json` ditulis otomatis oleh script pull.
